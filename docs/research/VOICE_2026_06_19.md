## Honest upgrade path (Apple-native default + Pro local upgrades)
**Yes — Apple-native is the MAS-safe default; Kokoro/Whisper are optional Pro/dev local upgrades.**
- **STT default = Apple.** macOS 26 `SpeechAnalyzer` is ~55% faster than Whisper Large-v3-Turbo, comparable/
better WER, ships in the OS (zero download, models outside the sandbox). The real seam already exists
(`EpistemosSpeechAnalyzer`) — **the upgrade is to actually route the macOS-26 composer mic through it**,
replacing the record-file→SFSpeech detour. Whisper (WhisperKit/MLX) = Pro accuracy option.
- **TTS default = AVSpeechSynthesizer (shipped).** Kokoro-82M = the right OPTIONAL upgrade (Apache-2.0,
on-device, **zero-Python Swift CoreML/ANE pipelines** — ~379ms/30s on Mac Studio). Install it LIKE A MODEL
via `ModelDownloadManager`, gate the picker on assets present, AVSpeech as instant fallback. MOSS-TTS =
later heavier slice (ONNX-Runtime, no turnkey Swift path — honest blocker). Cloud TTS/STT: SKIP for default
(local-first); Pro opt-in only, Keychain keys.

## Meeting/lecture note seam (MAS-safe) [ledger:2396]
record → on-device STT → Epdoc note + AI summary. Half-exists: capture via AVAudioEngine tap (live
SpeechAnalyzer — right for long-form, streaming partials, no 5-min file ceiling) OR record-file→AudioTranscriber;
STT Apple (MAS)/Whisper (Pro); → materialize transcript into an Epdoc/Tiptap note (editor infra exists); →
AI summary via the existing local/cloud chat engines. MAS-safe if STT stays on the Apple lane. Effort: medium
(new capture UI + record→transcribe→note glue; no new infra).
