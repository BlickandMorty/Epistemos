# Formal Math Company And Lean Intake - 2026-06-01

## Core Lock

The Axiom / Axiomatic AI / Harmonic / Math Inc / UlamAI wave is evidence that
the loop is now real enough to mine seriously:

```text
construct / search / formalize
  -> kernel-checked proof or bounded falsifier
  -> refactor / golf / repair
  -> human-readable explanation
  -> published or replayable artifact
```

Epistemos should preserve the full ambition. Do not collapse the architecture
into "a notes app with RAG" or "a small model cannot do that." Convert every
ambitious claim into a route card, verifier, falsifier, budget, rollback, and
AnswerPacket witness.

The matching rigor lock is just as strong: these external systems do not prove
that Epistemos already has AxiomProver, Ax-Prover, OProver, Aristotle, Gauss,
Axplorer, or UlamAI. They prove that the product should ingest their patterns,
source handles, benchmarks, and local open-code paths through existing organs.

## Architecture Mapping

Do not create a new authority organ called `FormalMathAgent`,
`LeanAuthority`, `ProofBrain`, or `MathRouter`. The route is:

```text
ProblemCard
  -> ConstructionGraph
  -> Eidos evidence / source-card intake
  -> EidosRoutePrior
  -> NeuralImportanceAtlas / ActiveAssembly support set
  -> RuntimeRouter tool route
  -> LeanProofRouteCard or ConstructionSearchRouteCard
  -> SCOPE-Rex / SovereignGate admission
  -> verifier output / failed proof / construction score
  -> Eidos post-validation and repair
  -> RunEventLog + AnswerPacket
```

This is the same architecture already used for local cognition. Lean,
Axplorer-style search, Ax-Prover/OProver-style proof pressure, UlamAI,
OpenGauss, LeanSearch, Pantograph, and mechanistic feature atlases are adapters
and evidence sources under existing organs.

## Product Laws

1. Preserve architectural ambition. The default response to "too big" is not
   "impossible"; it is "which bytes are cold, which bytes are hot, which bytes
   are active, and what verifier proves the selected route?"
2. Do not claim SSD is RAM. UAS/AppColdStore makes bytes addressable and
   routable. It does not erase latency, copy cost, or promotion budget.
3. Do not mutate base weights silently. Dynamic compute may pause, repair,
   swap adapters, restore KV, or exit early only through visible checkpoints.
4. Public code is source-mined first. No raw vendoring or copied code from
   Axplorer, Axiomatic AxProverBase, UlamAI, OpenGauss, Harmonic, LeanSearch,
   Pantograph, or lean4-skills without a separate license/setup/vendor PR and
   tests.
5. A Lean proof is a verifier witness, not the whole user answer. Epistemos
   still owes a human-readable explanation, citations, uncertainty, route,
   rollback, and replay handle.
6. Mechanistic features, SAEs, and "best region of the LLM brain" language are
   Pro Research priors until local activation, utility, interference, and
   dense/reference parity falsifiers pass.
