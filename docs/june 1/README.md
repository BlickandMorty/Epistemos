## Core Doctrine Compression

The full June 1 thread is not just PatternBoost. It is the stack from L11
through L20:

- L11 Constructive Residency: local capability comes from proof-carrying
  resident assemblies, not a whole model being hot.
- L12 Cache Lineage: persistent KV/prefix/cache/trace state promotes only with
  compatibility, staleness, privacy, wear, rollback, and witness gates.
- L13 Delta Projection: notes, graphs, projections, and editor state move
  through typed deltas, digests, parse forests, CRDT witnesses, and constrained
  mutations.
- L14 Engineering Logic: no mechanism enters architecture without invariant,
  owner, state transition, budget, failure mode, witness, and rollback.
- L15 Semantic Working Set: each mission compiles to predicted evidence, KV
  pages, adapter/model byte ranges, kernels, proof tools, budgets, prefetch,
  and observable misses.
- L16 Substrate Trace Observatory: routes, KV/cache pressure, sources, tools,
  and agent actions must be replayable, comparable, redacted, and tied to
  witnesses.
- L17 Verifier-Calibrated Sparse Wake: tiny scouts propose weights/KV/layers;
  verifier evidence, abstention, uncertainty escalation, and rollback decide.
- L18 ColdStream Residency Transport: token-hot cold bytes use explicit
  manifests, page runs, slab/Metal leases, codecs, cancellation, traces, and
  fallbacks instead of mmap-as-control-plane.
- L19 Copy-Causal Geometry: zero-copy is for backend/compute/transport/proof
  hot paths; intentional UI/product copies stay when they protect graph/editor
  variants, undo, previews, snapshots, and artifacts.
- L20 Pattern-Boosted Residency: offline/idle construction tournaments discover
  elite resident assembly motifs, repair/fingerprint/replay them, and only then
  distill route/layout policies with AnswerPacket-visible proof.
