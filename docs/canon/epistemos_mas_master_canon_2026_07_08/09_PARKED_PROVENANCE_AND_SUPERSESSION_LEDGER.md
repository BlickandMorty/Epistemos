## Compression safeguards

- Do not treat absence from active docs as deletion from history. The original
  ZIPs are preserved unchanged.
- Do not paste parked source text into an active build prompt without first
  checking this ledger and the active MAS lock.
- Do not cite a stale archive as authority when `research1.zip` through
  `research4.zip`, official sources, or local repo verification contradict it.
- When a local build agent needs old detail, attach the original source archive
  and this ledger together, then require an intent checkpoint before editing.
- If a source file appears important but is only in `source_map.json`, promote
  the idea surgically into the relevant active doc before using it as build
  direction.
