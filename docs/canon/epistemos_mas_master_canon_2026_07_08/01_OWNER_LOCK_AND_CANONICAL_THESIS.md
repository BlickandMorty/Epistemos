## Canonical thesis

Epistemos ships as one MAS-native knowledge app whose product authority is simple:

| Layer | Canonical answer |
|---|---|
| Active product surface | `Epistemos-AppStore` only |
| Active agent | None in free V1; MAS/June is the sole future paid agent, backed by in-process `agent_core` when explicitly reactivated |
| Active storage truth | User-visible vault markdown files, dataset artifacts, legal media/artifacts |
| Active editor truth | LUMENLENS Epdoc/editor/provenance/notebook plus vault-native task/planner/Meeting seams |
| Active data truth | RECKONER vault CSV/XLSX/`.icalc`/`.dataset.md` artifacts; IronCalc for calculation; GRDB derived |
| Active free capabilities | Meeting, Sync, Quick Capture, calendar/tasks, PDF/import, Kokoro/local speech, graph/search, workspace, and export through shared vault/provenance/event seams |
| Future paid capabilities | MAS June/Epdoc Assist, Browser, and ResearchHub; hidden and inert in free V1 |
| Active release gate | KEELSTONE storage, pruning, MAS legality, entitlement/privacy, leak scans, and soak tests |

The active canon should be smaller than the input corpus but stronger than any
single input ZIP. Compression is valid only when the nuance is retained in one
of the active docs, explicitly parked, or marked forbidden for MAS.

## Settled decisions

Confidence: HIGH.

1. **One MAS lane only.** Older Pro/Experimental/1Code/Goose/Kindred lanes cannot remain active.
2. **KEELSTONE first.** Storage truth, sandbox access, write safety, pruning, and archive evidence decide what everyone else can depend on.
3. **Storage verdict: HYBRIDIZE.** Keep file/artifact truth, add append-only provenance/op-log and stable IDs, keep GRDB/search/graph/cache rebuildable.
4. **MiniChat verdict: future paid MAS-June owned.** Hidden and inert in free V1; no Goose, no 1Code, no Kindred runtime, no second chat authority.
5. **RECKONER shape: no Data room.** Datasets live as workspace tabs/embeds;
   free V1 uses deterministic UI/editor actions, and future paid June may use
   the same staged/approved data tools only when reactivated.
6. **ResearchHub source policy: official APIs/RSS/OA/BYO only.** No illegal or ToS-violating sourcing.
7. **Free-V1 workspace verdict.** Epdoc tasks/planning and Meeting use readable vault truth and derived projections; no task, planner, Meeting, transcript, calendar, or sync database becomes a second authority.
8. **Paid visibility verdict.** Browser and ResearchHub remain MAS-safe future paid capabilities and are gated with June, including routes, shortcuts, deep links, restoration, provider startup, and background jobs.
9. **Free graph and notebook verdict.** Chat, agent-run, raw-thought, tool-trace,
   model, and paid-only artifacts are excluded from free-V1 graph and notebook
   projections at query/build/default/filter/restoration boundaries; stored data
   remains durable, not free-visible UI.

## Contradiction policy

When a source conflicts with this lock:

1. Keep the idea if it can be rebuilt through MAS-safe June/native/bundled-WKWebView/in-process `agent_core`.
2. Mark the old runtime/surface/transporter as parked provenance.
3. Mark local facts as `REQUIRES LOCAL VERIFICATION` unless the live repo was inspected.
4. Mark anything that violates Apple policy, source ToS, or owner lock as `FORBIDDEN_FOR_MAS`.
