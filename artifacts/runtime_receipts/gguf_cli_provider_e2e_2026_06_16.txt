KNOWN REFINEMENT (tracked, non-blocking — engine is flag-OFF + not UI-reachable):
  llama-cli b9370 is an interactive REPL: it prints its banner ("Loading
  model...", ASCII art, build/model info, available commands), the echoed
  prompt ("> ..."), a "[ Prompt ... | Generation ... ]" footer and "Exiting..."
  to STDOUT even with --log-disable / --simple-io / --no-display-prompt.
  -no-cnv / --no-conversation is hard-rejected by llama-cli in b9370 ("please
  use llama-completion instead"). So clean chat output needs either (a) a
  banner/footer strip in the provider, or (b) a switch to a non-interactive
  binary (llama-completion / llama-simple). The witness asserts generation, not
  cleanliness; the strip lands before the engine is promoted toward UI use.
